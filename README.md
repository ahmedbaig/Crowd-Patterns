# crowd-patterns

Population and crowds: where people live, and when and where large crowds gather across Sydney.

## Phases

1. **Data survey:** population grids and census data, transport patronage, pedestrian counters, event calendars; licences and privacy (aggregates only).
2. **Questions:** pick the first question, e.g. how events change crowd and transit load around venues.
3. **Model:** a spatio-temporal forecast of crowd levels, joined with [transit-delays](https://github.com/ahmedbaig/transit-delays).
4. **Viewer:** heat maps over time on the geo platform.
